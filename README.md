# Galla downloads

Installers and automatic updates for **Galla**, your shop's digital cash box. This repository contains no source code.

Download from **https://galla.concilio.solutions/#download** or the [latest release](https://github.com/Sparsh-bit/galla-releases/releases/latest):

- **Mac (Apple silicon, M1 and newer):** `Galla-mac-arm64.dmg`
- **Mac (Intel):** `Galla-mac-x64.dmg`
- **Windows 10 and 11 (64-bit):** `Galla-win-x64.exe`

Installed apps update themselves. Powered by [Concilio Solutions](https://concilio.solutions).
